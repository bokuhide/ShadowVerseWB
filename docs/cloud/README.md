# クラウド参照資料と接続検証

2026-10-10準備。保存先は既存 `data/official-card-pool` ブランチ。`main` とは異なるため、読み込むブランチを必ず指定する。

## 作業開始

1. `AGENTS.md`、`AGENT.md`、`knowledge/handoff.md` を読む。
2. `data/metadata.json` で取得日を確認し、`recipes/current.json` の対象版を選ぶ。
3. `research/pro/20261010.json` の確認済み範囲と未確認事項を読む。
4. リポジトリを取得できる環境では `node scripts/validate_learning.mjs` を実行する。追加パッケージ・APIキー不要。
5. 能力更新や新たな調査は、その都度の依頼範囲で行う。無期限作業・定期実行は設定しない。

## 環境の区別

公式の[Codex Cloud環境説明](https://learn.chatgpt.com/docs/environments/cloud-environments)はComputer/browser useを現在の未対応機能に挙げている。一方、[Work Cloudの説明](https://learn.chatgpt.com/docs/enterprise/chatgpt-work-cloud-security)ではホスト型ブラウザーを使える構成があるが、利用可否は実際の環境と権限による。Web検索だけで動画の映像を読めるとは判断しない。

Work Cloudチャットで、PCのファイル・ログイン・ローカル実行に頼らず以下を試す。チャット作成だけでCodex Cloudのリポジトリ環境を公開設定したことにはならない。

|項目|合格に必要な実測|不足時の扱い|
|---|---|---|
|資料|指定版のDB・レシピ・事例JSONを開き、実数やハッシュを取得|検索の抜粋だけなら未検証|
|公式サイト|日程またはカードページの本文を開く|検索結果のタイトルだけなら未検証|
|YouTube|動画のタイトル・対象時刻へアクセス|ページ取得と再生成功を別記|
|字幕|指定時刻の実際の字幕を読み、要約と時刻を記録|既存事例を再述しただけなら未検証|
|映像|指定時刻の実フレームを取得し、見える範囲を記録|字幕だけなら映像解析は未検証|
|保存|クラウド内に結果ファイルを作り、再読込を確認|この検証は同一タスク内。別実行の永続性は別検証|

結果はPASS/PARTIAL/BLOCKED/NOT_TESTED、日時、実際の実行環境・手段、対象URL・時刻、観測、制限を記録する。PCを実際に電源オフした試験と同一視しない。結果は新規成果物として保存し、公開前に機密情報がないか確認する。

## 公開範囲

カードデータ、3レシピ、公開プロ配信の目録と短い要約、匿名化した判断ルールのみ。個人戦績・シートURL・元録画・個人画像は含まない。長い字幕転載や動画の複製も含まない。
